# Repository guidance

Read README.md, contracts/README.md and docs/extraction-ledger.md before implementation. The frozen SPEC-IDBIO-200 snapshot in ../governance/references/edge-verification/ governs verification design. Record specification/source hashes when extracting code.

Keep iOS and Android in this capability directory. Public face APIs are vendor-neutral and independent of document engines, the identity product and paid backends. Preserve model/preprocessing/route identity and portrait/selfie provenance. Hosts supply wording, policy identifiers and storage locations. Optional UI stays separate from headless processing.

Preserve unrelated source-checkout edits and lawful attribution. Do not copy restricted vendor/model assets or real biometric data into the repository. Owner-authorized sample experiments use an explicit external workbench with provenance; keep all images, private indexes, environments and generated weights outside Git. Distinguish scaffold, implemented inference, native builds, integration and physical/evaluation receipts. Run affected native builds; macOS compilation alone does not establish iOS compilation. No commit, remote creation, publication or deployment is implied by local implementation work.

Read docs/qa.md before extraction. Run npm run check and each affected native lane. Zero-debt guards have no baseline suppressions. Carry behavior tests, synthetic fixtures and relevant assurance harnesses with each extracted component; extend guards in the same change for new modules, languages, dependencies or assets. Public API snapshots require explicit compatibility/versioning review.
