# Optional presentation guidance

Follow [root guidance](../AGENTS.md) and [APP-ARCH-001 revision 0.2](../governance/architecture/APP-ARCH-001.md). This optional module implements the [demonstration contract](../contracts/presentation-v1.md); it is not a capability evidence or identity-authorization API.

Keep controllers independent of UI, sensors, inference, transport and storage. Renderers receive prepared state and events. Preserve token binding, invalidation-before-cancel and both platforms' shared positive/negative vectors. Every emitted copy key must exist in the shared JSONC catalog. Update the classified source inventory and reviewed tooling locks with governed changes.

Run root `npm run check`, then `python3 scripts/presentation_check.py --platform macos` and `--platform android`; native host changes also require the iOS device/simulator/UI lanes. Keep executed source/native/manual evidence separate. No commits, publication or deployment are implied by implementation work.
